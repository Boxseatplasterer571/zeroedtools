01 / Project positioning

One practical workspace for the settings behind competitive FPS play

FPS setup work is usually scattered across a calculator, a click tester, a controller utility, a monitor page, and several game-specific references. ZeroedTools organizes those jobs around questions players actually ask: Is my sensitivity equivalent in another game? Is my input device behaving correctly? Is my display refreshing as expected? Can I reproduce the same measurement after changing hardware, firmware, or a game setting?

Comparable results

Use physical cm/360, eDPI where appropriate, and repeatable browser tests instead of relying only on a slider number or an impression that a setup “feels different.”

Immediate access

Open a focused diagnostic on the computer you are setting up without adding another software installation. This is useful at home, at a LAN setup, or after changing a peripheral.

Tools with current context

The global news center tracks noteworthy patches, competitive events, and releases so a new result or setting change can be viewed alongside what changed in the games players follow.

04 / How it works

Browser measurements, transparent limits, and no required installation

What happens in the browser

Interactive tests use browser input, timing, graphics, or gamepad capabilities to calculate and display a result on the page. Sensitivity tools apply documented conversion relationships and physical-distance calculations. Supported preferences can be reused without turning a quick test into a separate software installation workflow.

Browser timing depends on the device, operating system, browser, background load, and display pipeline. ZeroedTools therefore presents these utilities as practical diagnostics rather than laboratory-certified instruments.

Privacy and account requirements

The core public tests can be opened without a download or paid subscription. Test input used for an interactive browser measurement is handled by the tool running on the page. Standard site analytics, optional online features, and information a visitor intentionally submits are described in the official privacy policy.

05 / Typical use cases

When a quick, repeatable test is more useful than guessing

Switching games

Record mouse DPI and source sensitivity, convert to the target game, then verify the result in-game. A physical cm/360 reference avoids assuming equal slider numbers produce equal rotation.

Checking new hardware

Test mouse polling, click behavior, keyboard input, controller drift, or reported refresh rate after a new device, firmware update, cable change, or operating-system adjustment.

Narrowing down inconsistency

Run related tests one at a time to separate sensitivity, input, frame pacing, and display symptoms before changing several settings at once and losing a useful baseline.

09 / Frequently asked questions

Common questions about ZeroedTools

What is ZeroedTools?

ZeroedTools is an independent collection of browser-based FPS tools. It includes cross-game sensitivity conversion, aim and reaction tests, mouse, keyboard and controller diagnostics, display checks, and a global FPS news section.

Do I need to download or install anything?

No dedicated application installation is required for the public web tools. Open the relevant page in a modern browser and follow the instructions shown for that test.

Why use cm/360 instead of copying the same sensitivity number?

Games interpret sensitivity sliders at different rates. Cm/360 measures the physical mouse distance required for a full rotation and creates a shared reference across games. eDPI is most useful for comparing settings inside the same title.

Are browser hardware tests perfectly accurate?

They are practical diagnostics, not laboratory instruments. Results can be influenced by browser timing, firmware, operating-system settings, background load, and the display pipeline. Repeat a test under consistent conditions and confirm important findings with device or in-game settings.

Is ZeroedTools affiliated with a game publisher?

No. ZeroedTools is independent and fan-built. It is not endorsed by Riot Games, Valve, Electronic Arts, Activision, Blizzard, Krafton, Epic Games, Ubisoft, Embark Studios, TiMi Studio Group, Tencent, or other game publishers. Game names and trademarks belong to their respective owners.

Is the main ZeroedTools application open-source?

No. The live application is closed-source. This public repository contains only this static brand gateway and links to the live service; it does not contain the application source code.
