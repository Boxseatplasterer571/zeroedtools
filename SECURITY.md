# Security

This repository is only a static brand portal. The main ZeroedTools application is maintained separately and is not open source.

Please do not disclose security-sensitive details in a public GitHub issue. Report a suspected vulnerability through the official contact page:

<https://dfaccount.com/en/contact>

Include the affected URL, a concise description, reproduction steps, and the potential impact. Do not include real credentials, access tokens, personal data, or destructive proof-of-concept material.
